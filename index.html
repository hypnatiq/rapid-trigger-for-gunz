Page 02 · One dash and the key travel behind it

Follow one dash from the first press to the second press.

Begin with the movement the player already knows. One dash uses a first press, a recognized release, and a second press. Actuation begins that cycle; Rapid Trigger changes what can happen after it.

What you do in GunZ

Press one direction twice to create one dash.

A dash back still needs its own double-tap. You still perform both taps yourself. Rapid Trigger only changes how far you need to lift and press the key between them.

How the tuning order connects to the key cycle

Preserve the first press, build the re-press, then clean the release.

Actuation establishes the familiar first tap. RT A is tuned next so consecutive presses can continue. RT D is tuned after that to reduce the upward travel that clears the first tap. During the physical key motion, the RT D release still happens before the RT A re-press.

Continue with one directional double tap

See the key cycle behind one GunZ dash.

This diagram follows one directional key through the two taps of a dash: first tap, release, second tap.

GunZ move first

Press one direction once, release it, then press that same direction again.

Those two taps and the release between them must finish within a short input window. The OpenGunZ client source sets the full press, release, press sequence to 0.2 seconds, or 200 milliseconds. A private server can change its client code, so 200 ms is a documented GunZ-source reference, not a guaranteed measurement for every server.

Why Rapid Trigger matters inside that window: after the first tap, RT D can make the keyboard recognize the release with less upward key travel. Once you reverse the key, RT A can make the keyboard recognize the second tap with less downward travel. This reduces the physical distance your finger must cover. It does not increase GunZ's dash window.

02The key remains heldThe keyboard keeps recognizing the key while you continue pressing.
03 · RT DFirst tap is releasedThe key moves upward by the selected RT D distance, and the keyboard stops recognizing it as held.
04Key travel reversesYour finger stops lifting and starts pressing the same key again.
05 · RT ASecond tap is recognizedThe same key moves down by the selected RT A distance.

Plain rule: actuation sends the first tap, RT D controls how much you lift before the keyboard recognizes its release, and RT A controls how much you press again before the keyboard sends the second tap.

Common player question

Why do I keep tumbling even though I know the move?

Knowing the movement does not guarantee that every press is released and recognized cleanly. If the keyboard still recognizes the first tap as held when you begin the second tap, GunZ may not receive the input sequence you intended.

Rapid Trigger reduces the key travel needed between those inputs. It does not perform the movement for you or prove that every mistake comes from the keyboard. It gives you shorter, adjustable release and re-press distances to test.

Keep your familiar GunZ settings, binds, mouse, and movement unchanged at first. The goal is to make the way you already play cleaner and more repeatable, not to relearn everything at once.

Mechanical-to-Hall Effect actuation comparison

Compare the same 2.00 mm actuation and 4.00 mm travel.

Cherry MX Red comes first because it supplies the familiar fixed reference. The Hall Effect side uses a Wooting-compatible Lekker V2 L60, a medium linear 40–60 gf switch with the same 4.00 mm total travel. Its actuation is set to 2.00 mm for this comparison. The switches do not have identical force curves or reset behavior; the shared values isolate where the first input begins.

CHERRY MX RED · MECHANICAL

Ducky One 2 · fixed first-press point

2.00 mm actuation4.00 mm total travel
  1. Begin at 0.00 mm: the key is fully released and OFF.
  2. Press to 2.00 mm: the fixed mechanical contact sends the first input.
  3. Continue to 4.00 mm: the key bottoms out and remains ON.
  4. Lift back through its fixed reset behavior: the switch turns OFF before another press can be recognized.
  5. Press through 2.00 mm again: the next input turns ON at the same fixed point.

What is fixed: the switch construction determines where the input actuates and resets. Software does not move the Cherry MX Red contact point.

LEKKER V2 L60 · HALL EFFECT

Wooting-compatible · configured to the same first press

2.00 mm actuation4.00 mm total travel
  1. Begin at 0.00 mm: the key is fully released and OFF.
  2. Press to the configured 2.00 mm point: the keyboard sends the first input at the familiar depth.
  3. Continue to 4.00 mm: the key bottoms out and remains ON.
  4. With Rapid Trigger OFF, lift through the configured actuation boundary: the keyboard recognizes the release.
  5. Press through 2.00 mm again: the next input turns ON at the same configured point.

What becomes adjustable: the Hall sensor continuously measures key position, so software can move the actuation point without changing the physical switch.

Same values do not mean identical switches. This comparison matches actuation depth and total travel so the first press is easy to understand. Spring force, force curve, housing, calibration, reset behavior, and bottom-out feel can still differ.

Actuation is the first-press anchor. Rapid Trigger will later shorten the release and re-press cycle, but the player can keep the familiar 2.00 mm first press until testing shows a reason to change it.

Page 03 · Establish one familiar first press

Choose one actuation point for GunZ and everyday typing.

Begin from a switch or actuation value the player already knows. Test with Rapid Trigger OFF, adjust only when a repeated problem appears, and keep one profile that works everywhere.

Build from the keyboard the player already knows.

Read why I changed actuation →
  • If the previous switch is known, begin near its documented actuation depth. A Cherry MX Red reference begins at a nominal 2.00 mm first press.
  • If the previous value is unknown, begin from the current comfortable profile. Do not force a new shallow value before learning how the player already presses.
  • Mimic the familiar first press, not the entire old switch. Spring force, bottom-out, reset behavior, calibration, and key feel can still differ.
  • Keep the GunZ setup fixed. Do not change keys, sensitivity, resolution, FOV, camera distance, crosshair, or client while establishing the keyboard baseline.

The first goal is familiarity. Rapid Trigger should be introduced as a repeat-cycle feature, not as a reason to relearn the first press.

Test actuation with Rapid Trigger OFF.

Read my first movement check →
  1. Start from a clean Hall Effect profile and save a copy. Use only actuation for this pass. Leave Rapid Trigger, SOCD, DKS, Mod Tap, and analog movement OFF.
  2. Test the first press from a fully released key. Perform one familiar dash or action from rest. Repeat it enough times to separate one mistake from a repeated problem.
  3. Test the complete RT-OFF keyboard behavior in GunZ. Use one repeatable route, such as moving from one Town spawn toward the other with natural double taps. This checks familiarity with the full fixed press-and-release cycle; it does not claim actuation caused every result.
  4. Type normally for several minutes. Use the same posture and pressure you use every day. Watch for accidental letters, repeated letters, missed presses, or the need to type more carefully.
  5. If the first press repeatedly feels too deep or late, lower actuation by 0.10 mm and repeat both tests. If resting pressure creates inputs, raise actuation by 0.10 mm.
  6. Stop when the same value feels familiar and intentional in GunZ and normal typing. Save that actuation value before enabling Rapid Trigger.

Actuation passes when: the player starts movement naturally, clears the RT-OFF route with familiar double taps, and types normally without accidental or missed inputs.

Keep one profile as the goal.

GunZ pass

  • The first press begins when intended from a fully released key.
  • The player can cross the same route without changing hand posture.
  • The result repeats across more than one short set.

Typing pass

  • Normal typing does not create accidental or repeated letters.
  • Expected letters do not require extra pressure.
  • The player does not need a separate typing actuation value.

If either side fails, the actuation point is not finished. This method aims for one everyday profile that can type normally and play GunZ before Rapid Trigger is added.

Keep the saved actuation when Rapid Trigger turns ON.

With Rapid Trigger OFF: actuation sets the first press, and the keyboard uses its fixed release behavior before another press can register.

With Rapid Trigger ON: the saved actuation still sets the first press from a fully released key. After that first press, RT D controls the release and RT A controls the next press after the key reverses direction.

Work only with actuation, RT A, and RT D. Keep actuation fixed, tune RT A for consecutive movement, then tune RT D for the release.

Do not relearn everything at once. Keep the playing base you already have and change only the keyboard value connected to the repeated input problem.

Page 04 · Build the next press

Tune RT A until consecutive movement works naturally.

RT A controls how far the player presses down after reversing before the keyboard recognizes the next tap. Tune it while actuation stays saved and RT D remains at a stable starting value.

controls when the keyboard recognizes the next tap.

Read my full RT A test →

Lower RT A means less downward key travel is needed after you reverse the key and press it again.

What can improve

  • The second tap or later repeated tap can be recognized with less downward travel.
  • Repeated movement can continue with less finger motion.
  • The next dash can stay closer to the firing moment you expect during slash shot.
  • Movement can feel cleaner when the keyboard keeps up with your intended rhythm.

What can go wrong

  • If RT A is too low, a small bounce or unplanned re-press can create an early repeat.
  • If RT A is too high, the next dash can arrive after the firing moment you expected.
  • A faster movement rhythm can feel wrong if your aim has not adjusted to it.
  • A value that works in training can still fail when an opponent changes your pace and attention.

The smallest number is not the goal. Keep the least re-press travel that remains intentional and repeatable.

Save actuation and hold RT D steady.

Read my first RT A pass →
  • Start here: actuation already gives the player a familiar and intentional first press.
  • Enable Rapid Trigger. Keep RT D at a stable starting value that already allows the key to release. Do not begin from the smallest RT D value.
  • Change RT A only. Leave actuation, RT D, mouse sensitivity, and every GunZ setting unchanged.
  • My documented starting example: I kept RT D at 0.55 mm while lowering RT A from 1.50 mm to 0.60 mm for consecutive movement.

The value is personal; the control rule is reusable. Preserve the known first press and release setting while judging only the re-press.

Change only RT A and repeat the same movement chain.

Read the solo-movement stage →
  1. Use one familiar movement chain while alone. Repeat slash shot or another sequence the player can already perform without thinking about the keys.
  2. Confirm the key still releases at the starting RT D value. If the first tap remains held, pause the RT A test and correct the release problem. RT A does not replace RT D.
  3. Watch the second and later repeated presses. One successful move from standstill is not enough. The movement must continue across several inputs.
  4. If the next press repeatedly arrives late or cannot register before bottom-out, lower RT A by 0.05 mm. Repeat the same chain with every other setting unchanged.
  5. If an extra or early repeat appears, raise RT A by 0.05 to 0.10 mm. The re-press has become too sensitive for the player's finger motion.
  6. Stop at the first repeatable re-press. Do not keep lowering RT A just because the keyboard allows it.

You are ready for RT D when: the movement chain continues while alone, each next press feels intentional, and no extra repeat appears.

What happened in my first RT A pass.

See the recorded result →
  • At 1.50 mm RT A and 0.55 mm RT D, I could perform one selected move from standstill, but the next inputs were difficult to continue.
  • I kept RT D at 0.55 mm and lowered RT A to 0.60 mm.
  • Consecutive moves and actions then worked while I was alone in the Training Room.
  • This pass did not yet include an enemy, crosshair tracking, or firing rhythm.
  • I carried the 0.60 mm RT A result into the RT D release test instead of changing both values together.

What to watch while tuning RT A.

Watch for

  • The second and later presses continue without bottoming out unregistered.
  • The movement chain remains fluent across more than one short set.
  • Each repeated press still feels deliberate.
  • The starting RT D value continues to release the key reliably enough for this pass.

Avoid

  • Do not choose the smallest number. Stop at the first value that makes consecutive movement repeatable.
  • Do not use RT A to solve a first-press or release problem.
  • If an early repeat appears, raise RT A and test again.
  • Do not add an enemy or change sensitivity until the solo movement chain works.
Page 05 · Clean the release, then recheck the complete cycle

If the return dash is not silent, test RT D.

RT D controls how much the player lifts before the keyboard lets go of the first tap. Tune it after RT A has already produced consecutive movement, then recheck both directions of the cycle.

controls when the keyboard recognizes the release.

Read my full RT D test →

Lower RT D means less upward key travel is needed before the first tap is no longer recognized as held.

What can improve

  • The first tap can reset with less lift.
  • You can begin the second tap sooner under the same finger motion.
  • The double-tap can be easier to complete inside GunZ's dash window.
  • Late-dash returns can feel cleaner and become easier to repeat.

What can go wrong

  • If RT D is too low, a tiny pressure change can release a direction you meant to hold.
  • If RT D is too high, the keyboard may still recognize the first tap as held when you begin the second tap.
  • A value that clears one dash can still fail during a longer movement chain.
  • One missed dash does not prove RT D is the cause. Change it only when the same release problem repeats.

Example, not a preset: 0.10 mm RT D requires very little upward travel, but it also leaves very little room for finger bounce or natural pressure changes. If a held direction releases accidentally, raise RT D and test again.

Carry the saved actuation and RT A result into this pass.

Read my first RT D pass →
  • Start here: actuation already feels familiar and RT A already supports consecutive movement.
  • Save those values before continuing. RT D is the only setting that changes during the release pass.
  • My recorded first pass: I carried 0.60 mm RT A forward and lowered RT D from 0.55 mm to 0.45 mm, then 0.40 mm.
  • Keep the same move and environment. Do not add an enemy or change sensitivity while isolating the standing late-dash release.

This is the next stage, not a new starting preset. Carry forward the actuation and RT A values that already passed for the player's own movement.

Change only RT D and repeat the same late dash.

Read the standing late-dash test →
  1. Leave actuation and RT A alone. Changing more than one value makes it harder to tell what cleaned the release.
  2. Use a late-dash return from standstill. Dash one direction, then late dash back. Treat each dash as its own two-press input.
  3. Confirm the opening dash is normal. Use familiar movement such as slash shot or half step before judging the return.
  4. Listen for the return dash. If it repeatedly fails to stay silent, the keyboard may still recognize the first tap as held when the second tap begins.
  5. Lower RT D by 0.05 to 0.10 mm. Less lift will be required before the keyboard recognizes the release. Repeat the exact same late dash.
  6. If held movement cuts off from tiny finger motion, raise RT D one step. The release has become too sensitive.
  7. Stop at the first repeatable release. Do not keep lowering RT D just because the keyboard allows it.

RT D passes when: the opening dash remains normal, the return becomes silent and repeatable, and held movement does not end from small pressure changes.

Recheck RT A after RT D changes the release.

Read the enemy-and-aim stage →

Lower RT D lets the key turn OFF with less upward travel. That can change the feel and rhythm of the complete cycle, but it does not mathematically require a higher or lower RT A value.

The release is clean, but the next press still arrives too late.Lower RT A by 0.05 mm and repeat the same movement-and-aim test.

Leave RT A unchanged when the complete cycle is already clean. In my recorded pass, lowering RT D to 0.40 mm did not make the next press early. The next dash was still late under aim, so RT A moved from 0.60 mm toward 0.35 mm.

Recheck RT D if the RT A adjustment changes the rhythm again.

Read why I retested release →
  • My first RT D pass stopped at 0.40 mm when the standing return became cleaner.
  • After RT A changed the movement-and-aim rhythm, the release problem appeared again.
  • I returned to RT D because the release symptom repeated, not because the RT D number was larger than RT A.
  • After actuation later changed to 1.20 mm, I restored RT A to 0.60 mm and RT D to 0.55 mm and rebuilt the cycle instead of carrying the older values forward.
  • The new-baseline training pass reached 0.80 mm RT A and 0.30 mm RT D. Clan War and TDM later reached 0.35 mm RT A and 0.15 mm RT D.

The recheck rule: RT A and RT D stay independent, but changing one can expose a repeated problem in the other part of the movement cycle.

Match the repeated release problem to RT D.

The first tap is still held when the second press begins.Lower RT D one small step so the release needs less lift, then repeat the same move.

These are opposite symptoms. Lower RT D only when release requires too much lift. Raise RT D when release happens too easily.

What to watch while tuning RT D and rechecking the cycle.

Watch for

  • The standing late-dash return becomes silent and repeatable.
  • The first tap releases before the second press begins.
  • The RT A movement chain still continues after the RT D change.
  • The complete cycle holds through more than one short set.

Avoid

  • Do not automatically compensate RT A. Raise or lower it only when a repeated re-press symptom appears.
  • If a direction releases too easily, raise RT D instead of chasing RT A.
  • Do not tune around one failed dash.
  • Do not change sensitivity until the complete keyboard cycle is ready for validation.
Page 06 · Training first, then Clan War and TDM

Validate the complete keyboard cycle in real GunZ.

Begin only after actuation, RT A, and RT D have each passed their controlled test. Training confirms the full movement cycle. Clan War and Team Deathmatch then test whether it still works while you use the map, aim, and react to enemy pace.

Pass 1 · Controlled movement

See my controlled result →
  1. Load the saved actuation, RT A, and RT D result.
  2. Confirm one first press from a fully released key still feels intentional.
  3. Repeat the familiar movement chain while alone.
  4. Repeat the standing late-dash return and confirm the release remains clean.
  5. Run the same short set more than once before treating the result as a pass.
  6. If one symptom repeats, return only to the setting that controls that part of the cycle.

Pass 2 · Clan War or Team Deathmatch

See my real-match result →
  1. Take the training result into Clan War or Team Deathmatch.
  2. Use the map and test movement in more than one direction while controlling your character and aiming.
  3. React to different players and different enemy pacing.
  4. Do not retune after one miss.
  5. If the same input problem repeats, check the setting that controls that part of the key cycle.
  6. Save the last setting that stays clean under pressure.

Why not Duel as the main test: most fights on Hall stay mainly left and right. That does not give the same full range of motion or map movement that Clan War and Team Deathmatch require.

How to decide whether the setting passed.

  • The move works alone: the setting passed the controlled movement test.
  • The move stays aligned with your aim in Clan War and TDM: the setting passed the pressure and full-movement test.
  • The same failure repeats: return to the setting that controls that part of the key cycle.
  • A different failure appears: stop changing the current setting and identify the new problem first.
  • The result works across sessions: save it as your next checkpoint.

Finish the keyboard tune before reconsidering sensitivity.

See why I added an enemy →
  • Cleaner movement can make your aim feel different. You may reach the next dash and firing moment more fluently than before.
  • Do not change sensitivity while the keyboard is still changing. That would move two causes at once and make the result harder to understand.
  • First confirm the keyboard in real fights. The movement should remain clean while you aim, shoot, and react to different players.
  • Only reconsider sensitivity after repeated movement mistakes are no longer the problem. You may decide that no sensitivity change is needed.

If you doubt a step: the Research Notebook shows the observations and corrections that led to this order.

Page 09 · Glossary

What each keyboard term means in GunZ.

Open a term for the plain definition first, followed by the part it changes in your movement.

Keyboard terms

Actuation point

Definition: the key depth where the keyboard first recognizes a released key as pressed.

GunZ connection: how far you press before the first tap of a directional input is sent.

Rapid Trigger

Definition: the keyboard recognizes a release and a new press from the distance and direction of the key's movement. It does not wait for one fixed reset point.

GunZ connection: it can reduce the key travel needed to release the first tap and recognize the second or later repeated tap.

RT D · Rapid Trigger Deactivate

Definition: the upward distance an active key moves before the keyboard reports it as released. This is the OFF state shown in keyboard software.

GunZ connection: how much you lift before the keyboard stops recognizing the first tap as held.

RT A · Rapid Trigger Activate

Definition: the downward distance after key-travel reversal before the keyboard recognizes the next press. This is the next ON state shown in keyboard software.

GunZ connection: how much you re-press before the keyboard recognizes the second or later repeated tap.

Key-travel reversal

Definition: the point where the physical key stops moving up and starts moving down again.

GunZ connection: it begins the re-press that can become the second or later repeated input. It does not mean your character changed direction.

Split sensitivity

Definition: Wooting's option for assigning separate downstroke/Activate and upstroke/Deactivate distances.

GunZ connection: RT A and RT D can be tested separately instead of sharing one number.

Continuous Rapid Trigger

Definition: a mode that keeps Rapid Trigger active until the key is fully released. Standard Rapid Trigger ends when the key rises above its configured actuation point.

GunZ connection: this mode changes how long Rapid Trigger remains active while you release a key. Keep the mode unchanged while comparing values.

Other keyboard software

Definition: another Hall-effect keyboard may use different names for the same upward and downward key controls.

GunZ connection: check what the setting does, not only what it is called, before following the RT D or RT A steps.

SOCD / Snappy Tappy

Definition: a separate feature that decides how opposing directions are resolved.

GunZ connection: it can change directional output without changing Rapid Trigger, so record it and keep it fixed during an RT test.

Total travel and bottom-out

Definition: total travel is the full physical distance from the released top to the deepest position; bottom-out is that deepest position.

GunZ connection: it sets the physical space available for the first press, release, key-travel reversal, and second press.

Guide terms

Directional double press

Definition used here: the two presses of the same direction that produce one dash.

GunZ connection: this guide focuses on the keyboard recognizing a release between those presses and recognizing the second press in time.

GunZ base

Definition used here: a saved, repeatable starting profile that you do not change during comparison.

Checkpoint

Definition used here: a saved value that passed its current test stage and can be restored if the next change performs worse.

Dead dash

Definition used here: a dash you expected did not complete.

GunZ connection: if it repeats, check whether the keyboard recognized the release between the two taps and then recognized the second tap.

RT A-ready boundary

Definition used in the tester: the deepest point where there is still enough key travel left to complete the selected RT A distance before the key bottoms out.

Limit: it is only a visual guide in this tester. It is not a Wootility setting, an OFF point, or a server timing measurement.

Training calibration

Definition used here: a controlled test of a familiar move before an opponent and pressure are added.

CW/TDM validation

Definition used here: testing the training result in Clan War or Team Deathmatch before saving the setting you prefer.

GunZ connection: real opponents change your pace, aim, and attention in ways a solo training test cannot.

Page 10 · What supports the GunZ method

What I can support, and what is still personal.

The sources explain how the keyboard and GunZ input window work. My own tests explain why I changed each value and where I stopped.

What the sources support

  • The OpenGunZ client source uses 0.2 seconds, or 200 milliseconds, for the full press, release, press sequence.
  • Rapid Trigger follows the direction and distance of the key instead of waiting for one fixed reset point.
  • Split sensitivity lets the release distance and the re-press distance use separate values.
  • A smaller selected distance requires less physical key travel.

What I am not saying

  • I am not saying that every private server uses the OpenGunZ timing without changes.
  • I am not saying that my profile is correct for every player or keyboard.
  • A millimeter value is not a fixed number of milliseconds.
  • Rapid Trigger still does not replace movement practice or explain every missed input.
