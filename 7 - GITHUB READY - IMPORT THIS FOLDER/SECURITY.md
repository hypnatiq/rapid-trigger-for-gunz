# Security and Privacy

This is a static documentation and testing site. It does not require accounts, collect credentials, or provide a server-side submission endpoint.

## Report a concern

Open a GitHub issue only for concerns that can be described without posting private data. Do not include credentials, personal information, session tokens, private server addresses, or screenshots containing sensitive details.

## Safe-use boundary

- Test keyboard settings in a controlled environment before competitive use.
- Save the starting profile and change one value at a time.
- Keep the keyboard mode and firmware constant during a comparison.
- Restore the saved profile if control becomes unstable or normal typing is affected.
- Do not treat the cycle tester as hardware telemetry or a latency measurement tool.
